# Uploading this repository to GitHub

1. Create a new empty GitHub repository.
2. Extract the release ZIP locally.
3. Upload the **contents** of the extracted `TB_smear_negative_triage_GitHub_ready` folder, not the ZIP file itself.
4. Keep the repository public only after confirming that no patient-level source data have been added.
5. After the manuscript is accepted/published, update `CITATION.md` with the final citation and DOI.

Do **not** add files under `private_workspace/` other than its README.
